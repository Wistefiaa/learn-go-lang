# 🚀 Go API Essential Learning

A repository tracking my learning journey through the **GO API Essential** course by **mikelopster**. This workspace is dedicated to mastering Backend Development using Go, Fiber, PostgreSQL, and Clean Architecture.

## 🎯 Objectives
* Understand Go programming syntax and fundamentals.
* Build high-performance RESTful APIs using the **Fiber** framework.
* Connect and manage relational databases using **PostgreSQL** and **GORM**.
* Understand and implement **Hexagonal & Clean Architecture**.
* Write Unit Tests to ensure code quality and reliability.
* Deploy Go applications using Docker and Google Cloud (Cloud SQL, Cloud Run).
